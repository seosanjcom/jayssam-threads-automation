# 제이쌤 신뢰 표현 기준

## 핵심 기준

제이쌤 계정은 진로·코딩·미래교육 정보를 다룰 때 신뢰 근거를 과장 없이 사용한다.

## 사용할 수 있는 표현

- 꿈길 인증 진로체험 운영 경험이 있는 10년차 교육자
- 교육부 진로체험 플랫폼 꿈길 인증 기관 운영 경험을 가진 교육자
- 진로체험 현장에서 아이들을 만나온 10년차 강사
- 진로·미래교육 현장 전문가

## 피할 표현

- 국가공인 진로전문가
- 교육부 인증 진로전문가
- 공인 진로상담 전문가
- 진로검사를 공식 판정해주는 전문가

## 운영 원칙

프로필, 카드뉴스 마지막 장, 중요한 진로 콘텐츠의 신뢰 문장에는 사용할 수 있다.
하지만 Threads 본문마다 반복해서 넣지는 않는다.

좋은 사용 예:

```text
꿈길 인증 진로체험 현장에서 아이들을 만나온 입장에서 보면,
검사 결과보다 중요한 건 아이가 반복해서 선택하는 활동의 방향입니다.
```

더 짧은 사용 예:

```text
진로체험 현장에서 보면, 검사 결과는 정답이 아니라 대화의 시작점입니다.
```

## 제이쌤 톤

자격을 내세워 권위를 세우기보다, 현장에서 아이들을 많이 본 사람의 관찰로 말한다.
부모에게 겁을 주지 않고, 바로 확인할 수 있는 공식 자료와 구체적인 해석 기준을 함께 준다.
