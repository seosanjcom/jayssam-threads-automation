# Revenue Automation PRD

## 1. Purpose

Build a multi-account content and affiliate revenue system that can grow from a first stable target of 3,000,000 KRW per month to a medium-term target of 5,000,000-10,000,000 KRW per month.

The system must not only post content. It must create daily monetizable content, attach the right revenue mechanism, block weak CPA posts, measure performance, and adjust the next day's topics from real results.

## 3. Non-Negotiable Operating Rules

1. Every blog account must queue at least 5 posts per day.
2. At least 2 posts per blog account per day must be shopping/CPA candidates.
3. Shopping/CPA posts must not publish without:
   - real affiliate link,
   - matching disclosure text,
   - product/search intent,
   - AEO score above the publishing threshold.
4. AdPost is supporting revenue, not the main daily target driver.
5. Threads is not the final monetization surface. Threads must create trust, replies, saves, and blog/product traffic.
6. Each account must keep its own role. Celebrity/product shopping belongs to Lifemagazine, not Offnote.
7. No income guarantees, fake proof, deceptive redirects, or hidden affiliate links.

## 5. AEO And Content Quality Requirements

Naver AI search makes answer-quality structure critical. Every blog post must be written for both humans and AI extraction.

### 5.1 AEO Required Structure

Each publishable blog post must include:

- search-intent title,
- direct answer in the first 3 lines,
- clear reader situation,
- comparison criteria or checklist,
- table when useful,
- FAQ section,
- updated date or current-condition note,
- next action,
- disclosure when affiliate links exist.

### 5.2 Quality Gates

| Gate | Meaning | Required Evidence |
| --- | --- | --- |
| SUA | Search-User-Action | query, reader situation, next action |
| AU | Authority-Usefulness | source, criteria, price, procedure, comparison |
| GU | Gain-Use | save-worthy checklist, buyer/user benefit, clear action |
| AEO | AI answer optimization | answer-first structure, FAQ, headings, concise criteria |
| CPA | monetization readiness | real link, disclosure, product intent, no placeholder |

Publishing threshold:

| Score | Action |
| ---: | --- |
| 90-100 | publishable |
| 85-89 | publishable only if CPA and disclosure are correct |
| 70-84 | rewrite before publishing |
| below 70 | reject |

## 6. Daily Workflow

### 6.1 Morning Planning

Time: 06:20 KST

System actions:

1. Generate at least 5 queued posts for each blog account.
2. Assign each post a content type.
3. Mark shopping/CPA posts as blocked until real affiliate links are attached.
4. Score each post for SUA, AU, GU, AEO, and CPA readiness.
5. Produce a daily operator report.

### 6.2 Link And Product Selection

For each shopping/CPA post:

1. Search Coupang and Naver Shopping candidates.
2. Prefer products with:
   - clear search intent,
   - seasonality,
   - sufficient price or commission potential,
   - enough reviews or recognizable category demand,
   - low confusion between similar products.
3. Attach one primary link and optional alternatives.
4. Add disclosure text in the body.
5. Keep the post blocked if the link is missing or still placeholder.

### 6.3 Blog Publishing

For each blog account:

1. Publish 5+ posts/day.
2. Use staggered posting windows:
   - 09:30-09:40,
   - 11:30-11:40,
   - 14:30-14:40,
   - 17:30-17:40,
   - 20:30-20:40.
3. Prioritize publishable posts with AEO score 85+.
4. Do not publish blocked CPA posts.
5. If fewer than 5 posts are publishable, generate replacement non-CPA search posts.

### 6.4 Threads Distribution

Threads posts must not be generic blog summaries.

Offnote Threads:

- turn one strong blog/side-income idea into a sharp expert post,
- add 2-4 information-expansion replies,
- focus on comments, saves, and blog traffic.

Lifemagazine Threads:

- use product curiosity and media moments,
- keep product details and affiliate disclosure in replies,
- route deeper comparison/search content to blog.

Jayssam Threads:

- build authority and trust,
- route to worksheets, consultation, lecture, or ebook assets.

### 6.5 Evening Performance Review

Time: 21:30 KST

Track:

- posts queued,
- posts published,
- blocked CPA posts,
- AdPost revenue,
- affiliate clicks,
- affiliate conversions,
- top 3 posts by click,
- worst 3 posts by no-click,
- Threads replies/likes/saves if available,
- tomorrow's topic adjustments.

## 9. Work Plan

Goal: make every account produce enough monetizable inventory.

Tasks:

- Add TAEMOMJO to blog account config.
- Add AEO scoring.
- Add real product candidate collection from Coupang/Naver.

### Phase 2: Publishing Reliability

Goal: make queued posts actually publish without manual chaos.

Tasks:

- Add blog publish status tracking.
- Add publish-ready queue.
- Add manual approval fallback.
- Add failure alerts.

### Phase 3: Conversion Optimization

Goal: raise clicks and conversion, not just content count.

Tasks:

- Track clicks per link.
- Track conversion and cancelled CPA cases.

- Rewrite low-click titles and first paragraphs.
- Expand winning topics into 3-5 derivative posts.

### Phase 4: Portfolio Scaling

Goal: reach 3,000,000 KRW/month, then scale toward 5,000,000-10,000,000 KRW/month.

Tasks:

- Add weekly revenue review.
- Assign account-specific topic lanes.
- Build digital product funnels for Offnote/Jayssam.
- Build sponsorship pitch assets for Lifemagazine.
- Stop or rewrite underperforming content types.

## 11. Decision Principles

- Revenue beats vanity metrics.
- Clicks beat impressions.
- Conversion beats clicks.
- AEO-ready useful posts beat generic AI posts.
- Missing CPA link means no publish.
- If a post cannot help a reader decide, compare, buy, apply, or save, rewrite it.
