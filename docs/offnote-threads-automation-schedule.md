# Offnote Threads 자동 발행 운영 규칙

오프노트는 텔레그램 입력이 없어도 매일 두 슬롯을 자동 발행한다. 텔레그램으로 보낸 수동 기록은 선택적인 우선 입력이며, 다음 발행 가능한 슬롯의 소재로 사용된다. 수동 입력이 없는 다른 슬롯은 `scripts/offnote_evergreen_observations.json`의 자동 소재 풀에서 선택한다.

## 기본 발행 시간

기본값은 한국시간 기준으로 1차 `15:30`, 2차 `21:30`이다. 실제 실행은 `.github/workflows/offnote-threads-automation.yml`의 5분 주기 실행이 `config/offnote-schedule.json`을 읽어 결정한다. 따라서 텔레그램에서 시간을 변경해도 GitHub Actions의 고정된 단일 시각에만 의존하지 않는다.

## 텔레그램 명령

| 입력 | 동작 |
|---|---|
| 일반 문장 | 다음 발행 가능한 슬롯에 우선 기록으로 저장한다. |
| `/기록 내용` | 일반 문장과 같은 방식으로 저장한다. |
| `/시간` | 현재 1차·2차 발행 시간을 보여준다. |
| `/시간 16:00 22:30` | 1차를 16:00, 2차를 22:30으로 변경한다. |
| `/help` | 사용 가능한 명령을 보여준다. |
| `승인`, `보류` | 기존 초안 승인·보류 동작을 유지한다. |

시간은 `HH:MM` 형식이어야 하고, 두 슬롯의 시간은 같을 수 없다. 잘못된 시간은 저장하지 않는다. 시간 변경은 **이후 실행되는 슬롯부터** 적용하며, 이미 지나간 슬롯을 소급 발행하지 않는다.

## 수동 입력의 안전 규칙

수동 입력은 8자 이상 500자 이하로 저장한다. 상품 링크, 제휴 링크, 댓글 유도 문구 등 오프노트에 맞지 않는 입력은 저장하지 않는다. 입력은 `outputs/afterwork-profit/offnote-daily-facts/YYYY-MM-DD.json`에 기록되며, 생성기는 텔레그램 수동 입력을 자동 소재보다 먼저 선택한다.

## 자동 발행 폴백

텔레그램 입력이 없는 날에도 자동 발행은 중단되지 않는다. 생성기는 최근 21일 중복 방지, 같은 날 두 슬롯의 소재 분리, 주제·문장 길이·끝맺음 분산 규칙을 적용한 뒤 상시 관찰형 소재 풀에서 각 슬롯의 초안을 만든다. 실제 게시가 완료되면 텔레그램 수동 입력은 사용 완료로 표시한다.

## 테스트 원칙

수동 입력 테스트는 기본적으로 드라이런으로 실행한다. 드라이런은 텔레그램 수신·스케줄 저장·우선 소재 선택·문체 검증까지 확인하지만 Threads 게시 API를 호출하지 않는다. 운영 워크플로에는 이 테스트와 전체 회귀 테스트가 포함되어 있다.
